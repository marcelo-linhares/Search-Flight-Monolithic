Open Questions for the Storm

Ana · Business Domain

What happens when the price drops, the user clicks the link in the alert, and the price has already gone back up? Does the domain capture PriceAlertExpired?

Ana · Business Domain

Can a user set a maximum acceptable price threshold, not just watch for any drop? This changes the shape of WatchRequest and what "drop" means.

Ana · Business Domain

Should WatchRequest track FlexibleDates (±3 days)? Kiwi.com is built around this. If so, the Scheduler and Search contexts change significantly.

Marcus · DDD Architect

Is SearchPolicy a value object embedded in WatchRequest, or a separate aggregate? Its lifecycle (pause, resume, expire) suggests it needs its own root.

Marcus · DDD Architect

PriceSnapshot — is it an entity with identity (so you can compare snapshots over time) or a value object? If the Pricing context needs historical analysis, it must be an entity with a timestamp ID.

Marcus · DDD Architect

The Ledger context is missing from the board. Billing owns purchasing; Ledger owns debit/balance. These should be two contexts. Have you separated them in code?

Lena · Platform Engineer

Your in-process EventEmitter is synchronous by default in Node.js. If DebitCredits throws inside a PriceSnapshotCaptured handler, what's the rollback strategy? You need explicit error boundaries per handler.

Lena · Platform Engineer

SearchJobFailed is on the board but what triggers it? Retry logic (2 attempts? 3?) and the dead-letter path need to be first-class domain events, not just try/catch.

Lena · Platform Engineer

For your TCC experiments: how do you measure the cost of crossing context boundaries in-process vs. extracted to microservices? You need a benchmark harness that can run the same flow both ways.
