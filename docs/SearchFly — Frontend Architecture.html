Frontend Architecture — Micro-Module View
Expo managed · Expo Router · Zustand · Yarn workspaces monorepo · React Native (iOS + Android)
Stack decisions
Runtime
Expo Managed + Expo Router
File-based routing mirrors Next.js conventions; OTA updates ship fixes without App Store review; no native modules to maintain beyond the two managed ones.
State
Zustand + shared EventBus
One Zustand store per BC module keeps state ownership explicit. The shared EventBus store mirrors the server EventEmitter — the same DDD event-driven pattern at both layers, which is a thesis argument.
Monorepo
Yarn workspaces
apps/api and apps/mobile share packages/ (UI tokens, domain event types, config). One repo expresses the monolith philosophy end-to-end — backend and mobile in the same DDD boundary.
