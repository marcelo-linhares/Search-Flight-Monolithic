P0 — Credit Exhaustion & Reactivation

User story (one sentence): As a user whose watch was suspended because my credits ran out, I want to receive an alert immediately when that happens and have my watch resume automatically after I buy more credits — with no manual action required.

Implementation: 3 new domain events (WatchSuspendedDueToCredits, BalanceRestored, WatchReactivated), 3 new listener registrations across Watch Management, Notification, and Scheduler. No new bounded context, no schema migration beyond adding two event types to the event log.
